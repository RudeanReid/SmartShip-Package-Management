# SmartShip Package Management System

A Java Client/Server system for managing shipments, vehicles, payments, and reports.

## Features
- Customer, Clerk, Driver, Manager roles
- Shipment creation & tracking
- Vehicle scheduling & capacity validation
- Invoicing and payments
- Reporting (PDF export)

## Tech Stack
- Java SE (Swing or JavaFX)
- MySQL Database
- JDBC Connectivity
- GitHub for version control
